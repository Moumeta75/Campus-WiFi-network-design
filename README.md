# Campus WiFi Network Design

A Java Swing-based desktop application for designing and visualizing a campus WiFi network using **Kruskal's Minimum Spanning Tree (MST) Algorithm**.

## Features

- 📍 Interactive campus map visualization
- 🏢 Add and delete buildings
- 🔗 Add, edit, and delete network connections
- 🌳 Automatic Minimum Spanning Tree (MST) generation using Kruskal's Algorithm
- 💰 Displays total MST cost
- ⭐ Select and highlight a source building
- 🖱️ Drag and reposition buildings
- 💾 Save and load network data using text files
- 🖼️ Custom background map and building icons

## Technologies Used

- Java
- Java Swing
- AWT Graphics
- Kruskal's Algorithm
- Object-Oriented Programming (OOP)

## How to Run

1. Open the project in Apache NetBeans or any Java IDE.
2. Add the required background image and building icon.
3. Build and run the project.
4. Use the GUI buttons to manage buildings and network connections.

## Algorithm

The application uses **Kruskal's Algorithm** to compute the Minimum Spanning Tree (MST), ensuring the minimum total cable cost required to connect all buildings.
